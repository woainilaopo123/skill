# 基础概念

## 用途

当任务是解释医保术语、拆解金额概念、推导结算公式时，优先读取本文件。

## 核心术语

### 医疗费总额 / 患者费用总额

指患者本次就医发生的全部费用。

常见总式：

```text
医疗费总额 = 基金支付总额 + 个人现金支付 + 医院负担金额 + 其他支出
```

在结算分析中，最常用的简化关系是：

```text
总费用 = 医保报销金额 + 个人现金支付
```

### 医保结算范围费用总额

指医保政策范围内的费用总额，包含 `分类自负`。

### 非医保结算范围个人自费

指医保政策范围外、由个人承担的费用，常见包括：
- 全自费项目
- 超限价、超限额形成的自费部分

常见表达：

```text
个人自费 = 全自费 + 超限额自费
```

### 分类自负

指某些医保范围内项目中，按政策由个人先承担的部分，典型场景是乙类药、分类给付项目。

注意：
- 它属于医保范围内
- 但它通常会从可实际参与报销计算的基数里扣除

### 交易费用总额

指进入实际医保结算的费用基数，通常是医保范围金额扣除分类自负后的金额。

```text
交易费用总额 = 医保结算范围费用总额 - 分类自负
```

### 医保报销金额 / 基金支付总额

指医保基金或医保中心实际支付的部分。

不同上下文中可能叫：
- 医保报销金额
- 基金支付总额
- 统筹支付金额

### 个人自负

指医保范围内，在医保报销后仍由个人承担的部分。

抽象关系：

```text
交易费用总额 = 医保报销金额 + 个人自负
```

### 个人自付

在这些资料里，通常表示走医保路径中的个人承担金额，常见理解为：

```text
个人自付 = 个人自负 + 分类自负
```

### 个人现金支付

指患者实际掏出的钱，常见关系为：

```text
个人现金支付 = 个人自付 + 个人自费
```

展开后：

```text
个人现金支付 = 个人自负 + 分类自负 + 全自费 + 超限额自费
```

## 通用公式组

当任务没有明确限定平台时，优先使用这一组通用公式：

```text
总费用 = 医保结算范围费用总额 + 非医保结算范围个人自费
交易费用总额 = 医保结算范围费用总额 - 分类自负
交易费用总额 = 医保报销金额 + 个人自负
个人自付 = 个人自负 + 分类自负
个人自费 = 全自费 + 超限额自费
个人现金支付 = 个人自付 + 个人自费
总费用 = 医保报销金额 + 个人现金支付
```

## 关系树

```text
总费用
├── 医保结算范围费用总额
│   ├── 交易费用总额
│   │   ├── 医保报销金额
│   │   └── 个人自负
│   └── 分类自负
└── 非医保结算范围个人自费
    ├── 全自费
    └── 超限额自费
```

## 易混点

- `个人自费` 是医保范围外金额，通常不进入医保结算基数。
- `分类自负` 在医保范围内，但会影响实际可报销基数。
- `交易费用总额` 经常是“真正进入结算”的核心金额。
- 业务交流里，`个人自付` 与 `个人现金支付` 很容易混用，回答时要明确用户到底在问“医保路径中的个人承担”还是“患者最终实际支出”。
